1. SUMMARY OF VALUES TO REPLACE
================================================================================

A new user needs to know:
  1. AWS_ACCOUNT_ID        : 12-digit AWS Account ID (e.g. 123456789012)
  2. AWS_REGION            : AWS Region (e.g. ap-south-1)
  3. GITHUB_ORG            : GitHub username or organization (e.g. sumit-8125)
  4. GITHUB_REPO           : GitHub repository name (e.g. GITOPS-HITMAN-CLOUDFLUX-45)
  5. DOMAIN_NAME           : Your custom domain/hostname (e.g. app.example.com)
  6. SLACK_WEBHOOK_URL     : Slack Incoming Webhook for #alerts channel

3. DEPLOYMENT EXECUTION ORDER
================================================================================

1. Apply Terraform Infrastructure:
   $ cd Terraform
   $ terraform init
   $ terraform plan
   $ terraform apply

2. Update your local kubeconfig:
   $ aws eks update-kubeconfig --region ap-south-1 --name hitman-cloudflux-prod

3. Bootstrap Namespaces:
   $ kubectl apply -f Helm/bootstrap/namespaces.yaml

4. Apply RBAC:
   $ kubectl apply -f Helm/rbac/argocd.yaml
   $ kubectl apply -f Helm/rbac/aws-load-balancer-controller.yaml
   $ kubectl apply -f Helm/rbac/external-secrets.yaml

5. Deploy Platform Controllers (ALB Controller & External Secrets):
   $ helm repo add eks https://aws.github.io/eks-charts
   $ helm upgrade --install aws-load-balancer-controller eks/aws-load-balancer-controller \
       -n aws-load-balancer-controller \
       -f Helm/platform/helm-values/aws-load-balancer-controller-values.yaml

   $ helm repo add external-secrets https://charts.external-secrets.io
   $ helm upgrade --install external-secrets external-secrets/external-secrets \
       -n external-secrets \
       -f Helm/platform/helm-values/external-secrets-values.yaml

   $ kubectl apply -f Helm/platform/external-secrets/clustersecretstore.yaml

6. Deploy Observability Stack (Prometheus + Grafana + Alertmanager):
   $ kubectl apply -f Helm/argocd/monitoring-application.yaml

7. Deploy Applications via ArgoCD:
   $ kubectl apply -f Helm/argocd/backend-application.yaml
   $ kubectl apply -f Helm/argocd/frontend-application.yaml
